# 论坛系统 v2.0 测试计划

## 概述

本文档包含论坛系统 v2.0 的核心功能测试用例，覆盖用户注册、登录、发帖、回帖和搜索五大核心模块。

---

## 测试用例

### TC001 - 用户注册功能测试

| 项目 | 内容 |
|------|------|
| **用例ID** | TC001 |
| **功能模块** | 用户注册 |
| **测试目的** | 验证用户注册功能的正确性和边界处理能力 |
| **前置条件** | 系统已部署，数据库连接正常 |

#### 测试场景

| 场景 | 输入数据 | 预期结果 | 优先级 |
|------|----------|----------|--------|
| 正常注册 | 用户名: testuser, 邮箱: test@example.com, 密码: Test123! | 注册成功，跳转登录页 | P0 |
| 用户名重复 | 使用已存在的用户名 | 提示"用户名已存在" | P0 |
| 邮箱重复 | 使用已注册的邮箱 | 提示"邮箱已被注册" | P0 |
| 用户名过短 | 用户名: ab (少于3位) | 提示"用户名至少3个字符" | P1 |
| 用户名过长 | 用户名: a... (超过20位) | 提示"用户名最多20个字符" | P1 |
| 密码强度不足 | 密码: 123456 | 提示"密码强度不足" | P1 |
| 邮箱格式错误 | 邮箱: invalid-email | 提示"邮箱格式不正确" | P1 |
| 空值校验 | 所有字段为空 | 提示"必填字段不能为空" | P0 |

| 项目 | 内容 |
|------|------|

| **测试目的** | 验证用户登录认证流程和安全性 |

## 测试执行计划

### 测试环境
- **测试环境**: http://test.forum.v2.local
- **浏览器**: Chrome 120+, Firefox 121+, Safari 17+
- **数据库**: MySQL 8.0

### 执行顺序
1. TC001 用户注册（创建测试账号）
2. TC002 用户登录（获取登录态）
3. TC003 发帖功能（创建测试帖子）
4. TC004 回帖功能（验证互动功能）
5. TC005 搜索功能（验证内容检索）

### 通过标准
- P0级别用例100%通过
- P1级别用例90%以上通过
- 无严重缺陷（阻断性/致命性）
- 响应时间符合预期
